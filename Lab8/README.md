## Lab8 — Классификация методом k-ближайших соседей (kNN)

**Файл:** `Lab8.py`, `Wine_Quality_Data.csv`

**Что делали:**
- Загрузка данных о вине, отбор только красных вин
- Разбиение данных на обучающую и тестовую выборки (50/50) через `sample` и `drop`
- Формирование бинарной целевой переменной: `quality > 5` (хорошее / не очень)
- Выбор двух признаков для классификации: `volatile_acidity`, `alcohol`
- Построение **pipeline** из `StandardScaler` и `KNeighborsClassifier` — масштабирование признаков и модель в одном объекте
- Обучение модели для разных значений `k` (1, 5, 10, 20, 30, 50)
- Оценка качества через `accuracy_score` на тестовой выборке
- **Визуализация решающих границ** (`DecisionBoundaryDisplay`) для каждого `k` — 6 графиков в одном окне
- Добавление дополнительных признаков (`sulphates`, `citric_acid`) и повторный подбор `k`

**Стек:** Python, pandas, numpy, sklearn, matplotlib
