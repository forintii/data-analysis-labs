## Lab2 — Работа с Series и DataFrame в pandas

**Файлы:** `series-3.py`, `data.csv`, `data.txt`

**Что делали:**
- Чтение данных из текстового файла (с указанием кодировки `cp1251` и разделителя `\t`)
- Создание объекта `Series` с идентификаторами студентов в качестве индексов
- Разбиение серии на группы по количеству человек (`group1`, `group2`, `group3`)
- Модификация значений серии (добавление направления к имени)
- Выборка по индексам через `.loc`
- Преобразование данных через `.map`
- Фильтрация по строковым условиям: фамилия начинается с определённой буквы, имя — с определённой
- Загрузка данных в `DataFrame` из CSV
- Добавление новых столбцов: год поступления (через `.str[-4:]` и `.astype`), фамилия и имя (через `.str.split(expand=True)`)
- Удаление ненужных столбцов (`.drop`)
- Описательная статистика: среднее значение (`.mean`)
- Сортировка данных (`.sort_values`) и выборка по позиции (`.iloc`)
- Сложная фильтрация: по году и первой букве имени

**Стек:** Python, pandas
