## Lab3 — Анализ данных о продажах авокадо (pandas)

**Файлы:** `agg.py`, `avocado.csv`

**Что делали:**
- Загрузка и первичный осмотр данных (`head`, `info`)
- Поиск пропусков в данных: проверка, что для каждого региона, типа и даты есть запись
- Группировка данных (`groupby`) и агрегация (`agg`) — подсчёт количества записей
- Выявление регионов с неполными данными (количество записей меньше количества уникальных дат)
- Поиск конкретных отсутствующих дат через `set` и `isin`
- Группировка по дате и типу авокадо с расчётом min/max/mean цены
- Переименование столбцов, приведение таблицы к «широкому» формату
- Разделение таблицы на две (conventional / organic) и объединение через `join` с `lsuffix`/`rsuffix`
- Визуализация: 6 графиков цен в одном окне, настройка подписей осей
- Расчёт суммарного объёма продаж по датам для каждого типа авокадо
- Использование `apply` с кастомной функцией: максимальная цена только в дни, когда объём продаж был выше среднего
- Расчёт средней, медианной и **средневзвешенной** цены (вес — объём продаж)
- Визуализация динамики цен

**Стек:** Python, pandas, matplotlib

cd Lab3
