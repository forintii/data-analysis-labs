## Lab9 — Метод опорных векторов (SVM) с линейным ядром

**Файл:** `Lab9.py`, `Wine_Quality_Data.csv`

**Что делали:**
- Загрузка данных о вине и фильтрация: `total_sulfur_dioxide <= 250`, `volatile_acidity <= 1.4`, `quality > 6`
- Подсчёт количества записей после фильтрации
- Формирование признаков (`total_sulfur_dioxide`, `volatile_acidity`) и бинарной цели (`color == 'red'`)
- Построение модели **SVM с линейным ядром** (`SVC(kernel='linear', C=1.0)`)
- Вывод коэффициентов разделяющей прямой и свободного члена
- **Визуализация решающей границы** (`DecisionBoundaryDisplay`) с наложением точек данных
- **Анализ опорных векторов**: выделение объектов, попавших в `model.support_`
- Проверка, верно ли классифицированы опорные векторы
- Визуализация: опорные векторы, классифицированные верно (треугольники) и неверно (крестики)
- Сохранение графика в файл `task4.png`
- Вывод статистики: количество опорных векторов, верно и неверно классифицированных
