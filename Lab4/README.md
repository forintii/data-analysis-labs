## Lab4 — Регрессионный анализ (sklearn, numpy)

**Файлы:** `regression.py`, `regression2.py`, `avocado.csv`

**Что делали:**

**regression.py:**
- Фильтрация данных по типу авокадо (`conventional`) и выбор нужных столбцов
- Построение модели парной линейной регрессии (`LinearRegression`) для предсказания объёма продаж по цене
- Оценка качества модели: коэффициент детерминации (`r2_score`), среднеквадратическая ошибка (`mean_squared_error`)
- Визуализация: точки данных + линия регрессии
- **Реализация собственных функций** `my_fit`, `my_predict`, `my_r2`, `my_mean_squared_error` через `numpy.linalg.inv` — аналог методов sklearn
- Добавление нового фактора `meanvol` (средний объём продаж по региону) через `groupby` + `transform`
- Построение множественной регрессии с факторами `price` и `meanvol`
- Сравнение моделей: с двумя факторами, только с `meanvol`
- Вывод о том, какой фактор важнее

**regression2.py:**
- Фильтрация и подготовка данных
- Добавление фактора `kvol` = `volume` / `meanvol` — показывает долю объёма продаж в регионе
- Построение парной регрессии `kvol` от `price`
- Оценка качества (R², MSE)
- Вывод о низком влиянии цены

**Стек:** Python, pandas, numpy, sklearn, matplotlib

**Как запустить:**
```bash
cd Lab4
python regression.py
python regression2.py
