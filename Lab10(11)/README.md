## Lab10 — SVM с различными ядрами (RBF, полиномиальное) на Iris

**Файл:** `Lab10.py`

**Что делали:**
- Загрузка встроенного датасета Iris (`load_iris`) через sklearn
- Вывод информации о размерности данных, уникальных классах и примерах для каждого класса
- Выбор двух признаков для визуализации: `sepal length`, `petal length`
- **Исследование RBF-ядра**: обучение SVM с разными значениями `gamma` (0.1, 0.2, 0.5, 1.0, 2.0, 5.0)
- Визуализация решающих границ для каждого `gamma` (6 графиков в одном окне)
- Оценка accuracy для каждой модели
- **Исследование полиномиального ядра**: обучение SVM с разными степенями (`degree` = 2, 3, 4, 5)
- Визуализация решающих границ для каждой степени (4 графика)
- **Построение финальной модели** на всех 4 признаках с подобранными параметрами (`gamma=1`, `C=100`)
- Оценка accuracy финальной модели
- **Анализ `decision_function`**: вывод значений для первых 5 объектов и формы результата

**Стек:** Python, pandas, numpy, sklearn, matplotlib
