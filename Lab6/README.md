## Lab6 — Метрики классификации и ROC-анализ

**Файл:** `Lab6.py`, `Wine_Quality_Data.csv`

**Что делали:**
- Загрузка и фильтрация данных о вине (те же пороги, что в Lab5)
- Построение **множественной логистической регрессии** с двумя признаками: `total_sulfur_dioxide`, `volatile_acidity`
- **Собственная реализация матрицы ошибок** (`conf_matrix`) через подсчёт TN, FP, FN, TP
- Сравнение собственной реализации с `sklearn.metrics.confusion_matrix` для трёх порогов (0.25, 0.5, 0.75)
- Расчёт метрик классификации для порогов от 0.05 до 0.95:
  - Accuracy
  - Sensitivity (Recall)
  - Specificity
  - Precision
- **Собственная реализация метрик** через матрицу ошибок
- Визуализация зависимости метрик от порога (4 графика)
- **Собственная реализация ROC-кривой**: расчёт FPR и TPR для порогов от 0 до 1
- Сравнение собственной ROC-кривой с `sklearn.metrics.roc_curve`
- Расчёт **log loss** и **ROC-AUC** через sklearn
- Добавление третьего признака (`free_sulfur_dioxide`) и сравнение качества модели

**Стек:** Python, pandas, numpy, sklearn, matplotlib
