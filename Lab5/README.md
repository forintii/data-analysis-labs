## Lab5 — Логистическая регрессия: классификация вина по цвету

**Файл:** `Lab5.py`, `Wine_Quality_Data.csv`

**Что делали:**
- Загрузка датасета о качестве вина (`read_csv`), первичный осмотр (`info`, `head`)
- Фильтрация выбросов: отбор строк с `total_sulfur_dioxide <= 300` и `volatile_acidity <= 1.4`
- Подсчёт количества записей после фильтрации
- Разделение данных на красное и белое вино
- Визуализация распределений: гистограммы по `total_sulfur_dioxide` и `volatile_acidity` для двух типов вина (сравнение красного и белого)
- Построение модели **логистической регрессии** (`LogisticRegression`) для бинарной классификации: предсказание цвета вина (`red` / `white`)
- Две модели: по признаку `total_sulfur_dioxide` и по признаку `volatile_acidity`
- Вывод коэффициентов (наклон) и свободного члена (intercept) — интерпретация влияния признака
- Расчёт вероятностей через `predict_proba` для диапазона значений

**Стек:** Python, pandas, numpy, sklearn, matplotlib
