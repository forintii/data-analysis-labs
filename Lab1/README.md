## Lab1 — Основы numpy: векторы, матрицы, визуализация

**Файл:** `np_tasks.py`

**Что делали:**
- Генерация случайных векторов и матриц с фиксированным seed
- Векторные операции: сложение, фильтрация по условию (`&`, `sum`)
- Решейп массивов и агрегация (`reshape`, `sum`, `min`, `max`)
- Линейная алгебра: матрица поворота, обратная матрица (`np.linalg.inv`), умножение матриц (`@`)
- Визуализация данных: `matplotlib` — точечный график, линии, подписи, легенда

**Стек:** Python, numpy, matplotlib
